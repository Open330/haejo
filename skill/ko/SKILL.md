# 해줘

Haejo 스킬의 한국어 이름입니다. 같은 skills 폴더의 `haejo/SKILL.md`를 읽고 그대로
따르세요. 명령은 `haejo`입니다(`command -v haejo` 또는 `~/.local/bin/haejo`).

사용자가 “…해줘”라고 맡긴 일이 Mac 앱이나 웹 화면을 직접 다뤄야 하는 일이면, 그 요청이
작업 목표입니다(`--task new --goal "<요청>"`).
