브랜드 전략

Haejo는 반복 도구가 아니라, 부탁하면 해 주는 컴퓨터입니다

에이전트로 일하는 개발자와 파워 유저에게, Haejo는 실제 앱을 대신 쓰고, 결과를 확인하고, 무엇을 했는지 남기는 컴퓨터 사용 도구입니다. 화면을 보고 짐작하는 데서 끝나지 않고, 확인한 것만 끝났다고 말합니다.

이름 ‘해줘’가 곧 사용법이므로 모든 약속을 “~해 줘” 형태로 씁니다. 반복은 다섯 약속 중 하나입니다.

마크

ㅎ 한 글자: 해, 빈칸, 원

해 · 부탁

사용자의 “해줘”이자 떠오르는 해입니다. 작업이 시작되면 가로획 뒤에서 떠오릅니다. 워드마크 j의 점과 같은 해입니다.

가로획 · 빈칸

“Ask Haejo to ____”에서 부탁을 적는 밑줄입니다. 에이전트가 한 번 지나간 길(Flow)이기도 합니다.

원 · 확인된 결과

확인까지 끝나면 닫히는 원입니다. 상태 아이콘에서 채워지면 완료, 느낌표로 바뀌면 사용자의 판단이 필요하다는 뜻입니다.

점선 원이 원의 안쪽 구멍(지름 9.4)입니다. 해는 이 구멍과 같은 크기로 보이도록 0.72배로 그렸습니다. 꽉 찬 원은 같은 크기의 빈 구멍보다 커 보이기 때문입니다. 가로획은 원의 1.55배로 넓혀 마크가 정사각형을 가로로도 채웁니다.

전환 계획

이름은 지금 선점하고, 코드는 단계적으로 옮깁니다

  1. 이름 선점

    PyPI·npm haejo, 도메인, 상표 검색.

  2. 보이는 표면

    README 배너와 헤드라인, 사이트, 파비콘, 앱 아이콘, 공유 카드.

  3. CLI와 스킬

    haejo 명령 추가, tacto는 안내를 내는 별칭으로 한 릴리스 이상 유지.

  4. 앱 안의 브랜드 장치

    첫 실행의 부탁 입력란, 메뉴 막대 4상태, 실행 기록의 원 아이콘, 작동 모션.

  5. 내부 식별자

    번들 ID와 헬퍼 앱. TCC 권한을 새 신원으로 다시 받아야 하므로 안내 화면이 필요합니다.

  6. Python 패키지

    tacto/ → haejo/, 임포트 호환 심 유지 후 제거.
